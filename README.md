## התקנה (פעם אחת, ~20 דקות)

### 1. Repo ב-GitHub
צרי repo **פרטי** (`opencall-scanner`) והעלי את כל הקבצים.

### 2. הפעלת הדשבורד (GitHub Pages)
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, Folder: `/docs` → Save.
הכתובת תהיה: `https://<שם-משתמש>.github.io/opencall-scanner/`
> ⚠️ ב-repo פרטי, Pages דורש GitHub Pro (יש חינם לחודש ניסיון, או ~4$/חודש).
> חלופה חינמית: repo ציבורי — הדשבורד לא מכיל שום פרט אישי, רק לינקים ציבוריים,
> והסימונים שלך נשמרים רק בדפדפן שלך.

### 3. Secrets (Settings → Secrets and variables → Actions)

| שם | ערך |
|---|---|
| `ANTHROPIC_API_KEY` | מפתח מ-console.anthropic.com |
| `EMAIL_USER` | כתובת ה-Gmail שלך |
| `EMAIL_APP_PASSWORD` | סיסמת אפליקציה (Google → Security → App passwords) |
| `EMAIL_TO` | לאן לשלוח |
| `DASHBOARD_URL` | כתובת ה-Pages משלב 2 (ללינק במייל) |

### 4. הרצה ראשונה
Actions → Daily Open Call Scan → Run workflow.
ההרצה הראשונה תביא הרבה (הכל "חדש"); מהמחר — רק חדש באמת.

## הרצה מקומית / כוונון

```bash
pip install -r requirements.txt
python scanner.py --debug     # מה כל מקור מחזיר, בלי סינון ומייל
python scanner.py             # הרצה מלאה
```

## כפתורי כוונון עיקריים (scanner.py)

- `RELEVANCE_THRESHOLD` — סף האיכות (7). מרגישה שמפספסת? הורידי ל-6.
- `ARTIST_PROFILE` — לב הסינון. עדכני כשמשהו משתנה (למשל גיל הילדים, יעדים חדשים).
- `prep_days` בפונקציית reminder_links — כמה ימים לפני דדליין להתחיל לכתוב.
- `sources.yaml` — הוספת מקורות. מקור לא מחזיר כלום? `--debug` ותיקון סלקטור.
